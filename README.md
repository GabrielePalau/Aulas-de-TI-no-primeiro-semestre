# Aulas-de-TI-no-primeiro-semestre
Durante o primeiro semestre das aulas de Tecnologia da Informação, o principal conteúdo desenvolvido foi o Microsoft Excel. Ao longo das aulas, aprendemos desde as funções básicas da ferramenta até recursos mais avançados, como formatação de planilhas, organização de dados, criação de tabelas, utilização de fórmulas e funções, elaboração de gráficos, células fixas e análise de informações. 

O aprendizado do Excel é muito importante, pois essa ferramenta é amplamente utilizada em empresas, instituições de ensino e diversos setores profissionais. Saber organizar dados, realizar cálculos automáticos e apresentar informações de forma clara e objetiva facilita a tomada de decisões e aumenta a produtividade no ambiente de trabalho. Além de contribuir para o desenvolvimento de habilidades em informática, o conhecimento adquirido durante o semestre prepara os estudantes para desafios acadêmicos e profissionais, tornando-os mais capacitados para utilizar a tecnologia na resolução de problemas e na organização de informações.

Dessa forma, as aulas de Excel representam uma base importante para a formação e para o futuro no mercado de trabalho.
